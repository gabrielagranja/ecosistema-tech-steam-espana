Guía paso a paso

Sigue el orden y marca cada tarea al terminar.

01

Crea tu cuenta de GitHub

Si ya tienes una cuenta, salta al siguiente paso.

  1. Abre github.com y elige Sign up.
  2. Introduce tu correo, crea una contraseña y escoge un nombre de usuario.
  3. Completa la verificación y confirma tu correo.
Consejo: tu nombre de usuario aparecerá en la dirección pública de tu sitio.
02

Crea un repositorio nuevo

Un repositorio es la carpeta de GitHub donde guardarás los archivos de la web.

  1. Con sesión iniciada, pulsa New o el menú + → New repository.
  2. Escribe un nombre sencillo, por ejemplo portales-empleo-tech.
  3. Añade, si quieres, una descripción como «Explorador de portales de empleo tech en España».
  4. Elige si será público o privado y pulsa Create repository.
Visibilidad: GitHub Pages está disponible en repositorios públicos con GitHub Free. Publicar desde un repositorio privado depende del plan de GitHub; revisa la documentación de límites.
03

Sube tu archivo index.html

El archivo de entrada debe estar en la raíz del repositorio.

  1. En la página del repositorio, pulsa uploading an existing file.
  2. Arrastra index.html o selecciónalo desde tu ordenador.
  3. Escribe un mensaje, por ejemplo «Primera versión del sitio», y pulsa Commit changes.
Comprueba el nombre: debe ser exactamente index.html, en minúsculas, no Index.html ni index.html.html.
04

Activa GitHub Pages

Indica a GitHub desde qué rama y carpeta debe servir la web.

  1. En el repositorio, abre Settings → Pages (en «Code and automation»).
  2. En Build and deployment, selecciona Deploy from a branch.
  3. En Branch, elige main (o master) y la carpeta / (root).
  4. Pulsa Save.
Si no aparece la rama, vuelve a la pestaña Code y confirma que el archivo ya se ha guardado.
05

Abre y comparte tu sitio

GitHub compila y publica la página automáticamente.

  1. Espera unos minutos y vuelve a Settings → Pages.
  2. Cuando esté listo, aparecerá el enlace del sitio. Para un repositorio normal, tendrá este formato:
    https://tu-usuario.github.io/nombre-repositorio/
  3. Pulsa Visit site y comprueba que se ve correctamente.
Para actualizar: edita index.html en GitHub y confirma el cambio. Pages volverá a publicar el sitio automáticamente.
✓

Lista rápida antes de compartir

Marca lo que ya has comprobado. Tu progreso se guarda mientras mantengas esta pestaña abierta.

¿Algo no funciona?

Veo un error 404

Confirma que Pages está activado, que seleccionaste la rama donde subiste el archivo y que index.html está en la raíz. Tras guardar la configuración, espera unos minutos y vuelve a cargar la página.

He cambiado el archivo, pero no veo la actualización

Comprueba que el cambio se haya confirmado en la rama publicada y recarga el sitio. A veces el navegador conserva una copia anterior; prueba una recarga completa.

¿Por qué mi URL tiene el nombre del repositorio?

Los sitios de proyecto usan https://tu-usuario.github.io/nombre-repositorio/. El formato https://tu-usuario.github.io/ se reserva para el repositorio especial llamado tu-usuario.github.io.
