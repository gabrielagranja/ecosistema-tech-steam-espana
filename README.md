# Publica tu web con GitHub Pages

Una guía estática, responsive y en español para explicar cómo publicar un `index.html` en GitHub Pages.

## Publicar este proyecto

1. Crea un repositorio en GitHub.
2. Sube `index.html` a la raíz y confirma el cambio.
3. Abre **Settings → Pages**.
4. Selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`; guarda.
5. Espera a que termine la publicación y abre la URL que aparece en Pages.

No requiere dependencias ni proceso de compilación.
