# Ecosistema Tech & STEAM España

**Guía interactiva de portales de empleo y recursos profesionales de tecnología y STEAM en España.**

> **Estado: en desarrollo.** El contenido, las funcionalidades y los enlaces pueden cambiar mientras se revisa y amplía el proyecto.

🌐 **Web pública:** [gabrielagranja.github.io/ecosistema-tech-steam-espana](https://gabrielagranja.github.io/ecosistema-tech-steam-espana/)

## ¿Qué encontrarás?

- Un directorio de portales de empleo con filtros por experiencia, modalidad de trabajo y especialidad.
- Un asistente orientativo para explorar canales de búsqueda según tu perfil.
- Rangos salariales y una calculadora orientativa de equivalencia freelance.
- Un apartado de análisis y recursos sobre el mercado Tech y STEAM.

El objetivo es ayudar a explorar opciones y facilitar el acceso a fuentes externas. La guía no publica ofertas propias ni garantiza que una vacante siga disponible.
